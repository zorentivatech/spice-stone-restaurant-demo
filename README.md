# Spice & Stone — Restaurant Website Demo

Portfolio concept website created by Zorentiva Technologies. This is a fictional demo, not a paid client project.

## Preview
Extract the ZIP and open `index.html` in a browser. Internet is needed for Google Fonts and the sample Unsplash photos.

## Files
- `index.html` — content and page structure
- `styles.css` — styling and responsive layout
- `script.js` — mobile menu, menu filters and WhatsApp link

## Free GitHub Pages deployment
1. Create a new **public** GitHub repository named `restaurant-website-demo`.
2. Upload these three files to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for GitHub Pages to publish. URL format: `https://YOUR-USERNAME.github.io/restaurant-website-demo/`.

## Before any real client launch
Replace the fictional business name, address, phone, hours, menu and prices. Update the WhatsApp number in `script.js`. Use photos supplied by the client or properly licensed images. The contact CTA currently opens WhatsApp; it does not store form submissions.
